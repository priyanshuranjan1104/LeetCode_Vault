# LeetCode Vault

A collection of LeetCode solutions designed to strengthen problem-solving skills and build a solid understanding of data structures and algorithms. The repository contains solutions organized by problem number and title, primarily in Java, with selected solutions in JavaScript and SQL.

## Topics Covered

- **Arrays & Strings** — Array manipulation, string processing, and common coding patterns.
- **Linked Lists** — Traversal, reversal, and pointer-based operations.
- **Stacks & Queues** — Linear data structures and their applications.
- **Trees & Binary Search Trees** — Tree traversal, searching, and structural problems.
- **Graphs** — Graph traversal and related algorithmic problems.
- **Recursion & Backtracking** — Recursive problem-solving and exploring possible solutions.
- **Dynamic Programming** — Optimization through overlapping subproblems.
- **Greedy Algorithms** — Making locally optimal choices to solve problems.
- **Sorting & Searching** — Ordering, searching, and efficient data retrieval.
- **SQL** — Database queries and data manipulation challenges.

## Languages

- Java
- JavaScript
- SQL

## How to Use

1. Browse the repository and select a problem by its number or title.
2. Read the problem's `README.md` for its description and requirements.
3. Review the corresponding solution file.
4. Run the solution in the appropriate environment. Java solutions may use LeetCode's expected method signature rather than a standalone `main` method.

## Goal

To maintain a collection of coding solutions, reinforce core programming concepts, and continuously improve algorithmic thinking through consistent practice.
